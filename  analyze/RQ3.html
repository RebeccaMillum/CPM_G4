# boxplot + jitter + p-value from Wilcoxon test

plot_biomarker <- function(data, var, ylab) {
  d  <- data[!is.na(data[[var]]), ]
  wt <- wilcox.test(d[[var]] ~ d$Response, exact = FALSE)
  ggplot(d, aes(x = Response, y = .data[[var]], fill = Response)) +
    geom_boxplot(width = 0.6, outlier.shape = NA, alpha = 0.7) +
    geom_jitter(width = 0.12, alpha = 0.6, size = 1.2) +
    scale_fill_manual(values = group_colours) +
    # short x-axis labels so they don't overlap
    scale_x_discrete(labels = c("Non-responder" = "NR", "Responder" = "R")) +
    guides(fill = "none") +
    labs(x = NULL, y = ylab,
         subtitle = paste0("Wilcoxon p = ", signif(wt$p.value, 3))) +
    theme_classic(base_size = 11) +
    theme(plot.subtitle = element_text(size = 9))
}

p_pd1 <- plot_biomarker(df, "PDCD1", "PDCD1 (PD-1), TPM")
p_gep <- plot_biomarker(df, "GEP",   "T-cell–inflamed GEP score")

For each biomarker we report the group mediansnd and the Wilcoxon p-value

summarise_biomarker <- function(data, var) {
  d   <- data[!is.na(data[[var]]), ]
  med <- tapply(d[[var]], d$Response, median)
  wt  <- wilcox.test(d[[var]] ~ d$Response, exact = FALSE)
  data.frame(
    Biomarker      = var,
    n_NonResponder = sum(d$Response == "Non-responder"),
    n_Responder    = sum(d$Response == "Responder"),
    median_NonResp = round(med["Non-responder"], 3),
    median_Resp    = round(med["Responder"], 3),
    direction      = ifelse(med["Responder"] > med["Non-responder"],
                            "higher in responders", "higher in non-responders"),
    wilcox_p       = signif(wt$p.value, 3)
  )
}

conclusion

all three candidate biomarkers (PD-1, the 18 genes T cell inflamed GEP and TMB) were higher in responders than non responders and each of them differed significantly between two response groups. Proof for that showed wilcoxon test with p<0.001 for all of three, as it is seen in boxplot or summarytable

when it comes to the direction, TMB showed the largest relative shift (median 7 -> 14 mut/mb) and the strongest statistical evidence. GEP has the cleanest sepration of the two groups, which is seen on the boxplot-> the boxes barely overlapping. PD-1 showed the weakest assosiation out of all of them, with the most overlap between the groups.

the “strongest” biomarker depends on the criterion used: TMB wins on p-value and relative median change, whereas GEP best separates the groups visually. All of the 3 biomarkers represend very low p value.

when it comes to investigate biological meaning- each biomarker reflects a different part of the anti tumor immune response. TMB is a genomic measure of the number of somatic mutations. Pd-1 is a single gene read out activated/exhausted T cells. The T cell inflamed GEP summarizes a coordinated, multi-gene signal of an inflamed tumor microenvironment.

Limitations: these are group level associations in baseline samples, not balidated predictive biomarkers, so some of them overlap. Groups are strongly imbalanced between responders and nonresponders

To sum up, all three biomarkers are associated with response, with the strongest and largest relative effect for TMB and the cleanest group separation for GEP, but the overlapping distributions, imbalanced mean these should be interpreted as associations rather than clinically actionable predictors..
